Small thing to note. The `root` variable does two different things depending on whether we are in the `location` structure or `server` structure.

In `location`:

- Having a root variable changes the location URI from the given request and replaces it with the root variable to look for in the server.
    `/kapouec/hello.html` becomes `/tmp/www/hello.html` if the location structure has URI `/kapouec` and `root /tmp/www`

- Having a server root simply appends (prefixed)
    `somefolder/somefile.html` becomes `zivanov/somefolder/somefile.html` if `root zivanov` in the server structure.

NB: If root is set in location, we no longer append the prefix of the server root!
